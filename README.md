# internet-speed-test

Консольный скрипт на Python, который измеряет скорость скачивания: последовательно
запрашивает один и тот же URL, дочитывает каждый ответ до конца и считает среднее
время запроса, суммарный объём и скорость.

## Требования

- Python 3.9+
- Сторонние библиотеки не нужны, используется только стандартная библиотека

## Запуск

```bash
python speed_test.py "https://speed.cloudflare.com/__down?bytes=1000000"
```

Если `python` не прописан в `PATH` (Windows), используйте `py`:

```powershell
py speed_test.py "https://speed.cloudflare.com/__down?bytes=1000000"
```

В качестве адреса подойдёт любая тяжёлая картинка или файл, например
`https://speed.cloudflare.com/__down?bytes=5000000`. Сервер должен отдавать
файл без сжатия — иначе измеряется скорость скачивания уже сжатых данных.

### Интерактивный режим

Если запустить скрипт без адреса, он ждёт URL, выполняет замер, а затем
предлагает меню:

```text
$ python speed_test.py
URL (empty to exit): https://speed.cloudflare.com/__down?bytes=1000000
...
Requests:        10
Total size:      10.00 MB (10000000 bytes)
Total time:      5.592 s
Average request: 0.559 s
Download speed:  1.79 MB/s

1) repeat  2) another URL  3) exit
Choice: 1
```

- `1` (или просто Enter) — повторить замер для того же адреса;
- `2` — ввести другой URL;
- `3` — выйти.

Пустой URL или `Ctrl+C`/`Ctrl+D` также завершают работу.

### Параметры

| Параметр | По умолчанию | Описание |
| --- | --- | --- |
| `url` | — | адрес файла; если не указан, включается интерактивный режим |
| `-n`, `--requests` | `10` | количество последовательных запросов |
| `-t`, `--timeout` | `30` | таймаут одного запроса в секундах |

### Пример вывода

```text
URL:      https://speed.cloudflare.com/__down?bytes=1000000
Requests: 10, timeout: 30 s

 1/10      1.00 MB    0.459 s     2.18 MB/s
 2/10      1.00 MB    0.514 s     1.95 MB/s
 ...
10/10      1.00 MB    0.821 s     1.22 MB/s

Requests:        10
Total size:      10.00 MB (10000000 bytes)
Total time:      5.592 s
Average request: 0.559 s
Download speed:  1.79 MB/s
```

## Единицы измерения

- **Время** — секунды (`s`), выводится с точностью до миллисекунд.
- **Объём** — MB (мегабайты): 1 MB = 1 000 000 байт; в скобках — точное число байт.
- **Скорость** — MB/s (мегабайты в секунду): 1 MB/s = 1 000 000 байт в секунду.

## Как считаются показатели

- Каждый запрос выполняется после завершения предыдущего, ответ читается целиком
  (TCP-соединение и тело ответа), поэтому в замер попадает и время ожидания сервера.
- **Average request** = суммарное время всех запросов / количество запросов.
- **Download speed** = суммарный объём / суммарное время. Это средняя скорость за
  весь тест, а не среднее арифметическое скоростей отдельных запросов.
- Результат зависит от сервера, CDN, кеша и загрузки канала; для стабильных цифр
  запускайте тест несколько раз и берите файл побольше.
